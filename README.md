🎬 CINEVERSE - OTT Streaming Platform

CINEVERSE is a Modern OTT Streaming Platform web application built using **HTML, CSS, JavaScript, and Firebase Authentication**. It allows users to browse movies, watch trailers, manage their watchlist, continue watching their favorite content, and securely sign in using Google Authentication.

---

 🚀 Features

🔐 User Login & Signup

🔑 Google Sign-In with Firebase Authentication

👁️ Show Password Option

✅ Confirm Password Validation

👤 User Profile

👋 Welcome Notification

🚪 Secure Logout

🖼️ Profile Picture Upload & Remove

🎬 Movie Categories (Action, Drama, Horror, Romance, Sci-Fi, Survival, etc.)

🔍 Search Movies

▶️ Watch Movie Trailers

❤️ Add Movies to Watchlist

❌ Remove Movies from Watchlist

🚫 Duplicate Watchlist Prevention

📺 Continue Watching Section

🔄 Reset Watchlist & Continue Watching

ℹ️ Movie Details Popup

🎥 Dynamic Hero Banner Section

🖼️ Landscape Hero Banners

🎞️ Trailer Popup

🎨 Fully Responsive User Interface

🚀 CINEVERSE Splash Screen Animation

🔊 Original Cinematic Intro Sound

✨ Smooth Logo Animation & Fade-Out Transition

💾 Local Storage Support
